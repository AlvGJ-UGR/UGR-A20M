# 📸 Fotografías del proyecto UGR-A20M

Esta carpeta contiene el registro fotográfico del proceso de modificación.

## Estructura

```
photos/
├── estado-inicial/    ← Fotos ANTES de cualquier modificación
├── fase-1/           ← Proceso de instalación electrónica y extrusor directo
└── fase-2/           ← Guías lineales y refuerzo estructural
```

## Convención de nombres

```
YYYY-MM-DD_descripcion-breve.jpg
```

Ejemplos:
- `2025-04-10_vista-frontal-original.jpg`
- `2025-05-01_skr-mini-instalada.jpg`
- `2025-05-15_sharkfin-montado.jpg`
