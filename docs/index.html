ugr.es / AlvGJ-UGR / UGR-A20M

Modernización Geeetech A20M

Migración progresiva de una impresora 3D cartesiana a electrónica de 32 bits (SKR Mini E3 V3 + STM32G0B1), extrusión directa estilo Voron (Sharkfin + BMG Clone) y firmware Klipper sobre Orange Pi Zero 3. Proyecto educativo de la UGR, documentado para ser reproducible.

UGR · Proyecto educativo Fase 1 en progreso Fase 0 completada Klipper · 29 macros SKR Mini E3 V3 MIT License
Objetivos del proyecto
  • → Mejorar el rendimiento, fiabilidad y calidad de impresión de la Geeetech A20M
  • → Implementar extrusión directa de alto caudal (Sharkfin + CHC V6 Volcano)
  • → Instalar toolhead estilo Voron: Mini Stealth v2 con refrigeración dual 4010
  • → Migrar la electrónica a SKR Mini E3 V3 + Orange Pi Zero 3 con Klipper
  • → Reforzar la estructura con guías lineales MGN12H en X e Y (Fase 2)
  • → Generar una guía reproducible para estudiantes y makers de la UGR

Fase 0 Especificaciones e investigación completada

Análisis de la máquina original (GT2560 v3, Marlin 1.x, Bowden dual), comparativa de alternativas electrónicas, selección de componentes y creación de la estructura documental del repositorio.

docs/fase-0/ 00_especificaciones_base.md BOM_fase1.md

Fase 1a Actualización electrónica en progreso

Sustitución de la GT2560 por la BTT SKR Mini E3 V3.0 con STM32G0B1 de 32 bits. Instalación de Orange Pi Zero 3 con Armbian ejecutando Klipper, Moonraker y Fluidd. Configuración de los cinco drivers TMC2209 en modo UART con stealthChop.

docs/fase-1/electronica/ 01_skr_klipper.md firmware/klipper/config/printer.cfg
●
Fase 1b Extrusor directo Sharkfin + BMG Clone en progreso

Conversión de Bowden a direct drive con extrusor Sharkfin (KayosMaker) y engranajes BMG Clone a ~3.5:1. Motor NEMA 17 pancake de 20 mm. Calibración de rotation_distance, Pressure Advance y retracción mínima (~0.5 mm).

docs/fase-1/extrusor/ 02_sharkfin_bmg.md firmware/klipper/macros/macros.cfg
●
Fase 1c Toolhead Mini Stealth v2 + CHC Volcano en progreso

Shroud Mini Stealth v2 (atrushing) con hotend CHC V6 Volcano de alto caudal a 24 V. Refrigeración de capa dual simétrica con dos ventiladores radiales 4010 24 V. Autonivelación con CR-Touch y bed mesh bicúbico en Klipper.

docs/fase-1/toolhead/ 03_mini_stealth_chc_crtouch.md
Fase 2 Guías lineales MGN12H en X e Y planificada

Sustitución de las varillas lisas originales por guías lineales MGN12H en los ejes X e Y. Refuerzo del bastidor y rediseño de brackets de montaje para los carros.

docs/fase-2/ 04_guias_lineales.md
Fase 3 Benchmarks e informe UGR planificada

Pruebas de rendimiento comparativas antes/después en PLA, PETG y TPU. Publicación de GitHub Pages y entrega del informe técnico final a la UGR.

# firmware/klipper/macros/macros.cfg — 29 macros en 6 categorías

[gcode_macro START_PRINT]
gcode:
    {% set BED_TEMP = params.BED_TEMP|default(60)|float %}
    {% set EXT_TEMP = params.EXTRUDER_TEMP|default(200)|float %}
    M140 S{BED_TEMP}
    G28
    BED_MESH_CALIBRATE
    M190 S{BED_TEMP}
    M109 S{EXT_TEMP}
    G92 E0
    G1 Z2.0 F3000
    G1 X5 Y20 Z0.3 F5000
    G1 X5 Y200 E15 F1500      # línea de purga
    G92 E0

[gcode_macro END_PRINT]
gcode:
    {% set safe_z = [printer.toolhead.position.z + 10, printer.toolhead.axis_maximum.z] | min %}
    G91
    G1 E-4 F2700
    G90
    G1 Z{safe_z} F3000        # safe_z dinámico
    G1 X10 Y230 F3000
    M104 S0
    M140 S0
    M84

[gcode_macro FILAMENT_RUNOUT]
gcode:
    PAUSE
    M117 Filamento agotado — cambia y pulsa RESUME

[gcode_macro SET_MATERIAL]
gcode:
    {% set MAT = params.MATERIAL|default("PLA")|upper %}
    {% if MAT == "PLA" %}   {% set ET=200 %} {% set BT=60 %}
    {% elif MAT == "PETG" %}{% set ET=235 %} {% set BT=85 %}
    {% elif MAT == "ABS" %} {% set ET=250 %} {% set BT=110 %}
    {% elif MAT == "TPU" %} {% set ET=220 %} {% set BT=40 %}
    {% else %}              {% set ET=200 %} {% set BT=60 %}
    {% endif %}
    M104 S{ET}
    M140 S{BT}
